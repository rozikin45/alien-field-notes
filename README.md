A one-line alien tourist review of Earth (131 characters): five stars for the views, one star for the gift shop — it sells tiny models of the reviewer's own ship and calls them 'UFOs.' Would visit again. The program is fully deterministic and writes the review to entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
